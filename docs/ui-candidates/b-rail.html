B · Rail

The same list of blocks, drawn on a vertical rail. Each mark is a dot; the segment below it is as tall as the time it covers. You can see where the day went before reading a single number.

  • Height follows duration. 1.2 px per minute, a 48 px floor so a 12 s block stays tappable, a 140 px cap with a broken-axis squiggle for long blocks.
  • Points are punctuation. Marks are ink-black dots on the rail; time sits beside the dot, tag and duration sit in a tonal card.
  • Unlabeled looks unfinished. Hatched rail and a dashed ghost card invite a tap; labeled blocks are solid tonal fills.
  • One big action. A 72 px extended FAB, bottom center, in primary container. Everything else stays quiet.
  • Native to Android 16. Tonal surfaces, 18–30 px shapes, Google Sans Flex with full roundness on display text.
info
Layout, not a chart. The rail is how the existing rows are drawn: same rows, same order, same taps. It adds no totals, axes, or statistics, and nothing is computed that the list did not already show.
