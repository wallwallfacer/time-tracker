Candidate C · Time Tracker redesign

C · Terminal_

An OLED instrument panel that reads like a log file. Every block is one line of output; the only light on the panel is the amber signal for now and the Mark key.

  • One signal color. Amber means “live” or “press here”, and nothing else.
  • Rows are log lines. Time, tag and duration line up in mono columns with leader dots between them.
  • Unlabeled is shown as missing data: dim ?? UNLABELED with a blinking cursor waiting for input.
  • Hardware keys, not buttons: Mark and the tags are keycaps with a 3px bottom bevel.
  • Pure #000 and 1px hairlines on an 8px baseline. Lit pixels stay few, which saves power on OLED and suits always-on.
