Swiss

The day as a railway timetable: departures on a strict four-column grid, black on white, and one signal color — red means now.

Principles

  1. One grid. Four columns, 22/16px gutters. Start · Tag · Tag · Duration. Nothing floats.
  2. Type is the interface. 56px day title, 22px times, tabular figures everywhere.
  3. Red = time. Only Mark, the live block and capture are red. Nothing else may use it.
  4. Color is a bar, not a fill. Tag hue lives in a 6px edge bar + square bullet; the name carries meaning.
  5. Rules, not cards. 4px rules open sections, hairlines separate rows. No radii, no shadows.
